FastNLR

FastNLR scans the six reading frames of a genome assembly for amino-acid motifs and assembles them into complete and partial NLR loci — a from-scratch Rust port with multithreading, checkpoint resume, and several bug fixes over the original.

Features

Built for speed, shipped self-contained

A drop-in replacement for NLR-Annotator that runs out of the box on any FASTA — no config files, no setup.

High performance

Rust with rayon multithreading, memory-mapped FASTA parsing, and SIMD (wide) cross-window scoring. Plant genomes finish in seconds to minutes.

Zero-config binary

The standard mot.txt (PWM) and store.txt (CDF) configs are embedded at compile time. Run on any FASTA with no extra files.

Coordinate-consistent

Loci extraction (-f) matches GFF/BED coordinates exactly, fixing the original Java off-by-one and multi-contig bugs.

Resumable runs

--checkpoint saves motif results after the scan; reruns skip the expensive scanning step and go straight to assembly.

Rich reporting

Human-readable summary, TSV statistics (global / per-chromosome / per-motif), and PNG plots out of the box — no external tools.

Original flag compatible

Drop-in for existing -i/-x/-y/-o/-g/-b/-m/-a/-f/-c/-t/-n workflows. Swap the binary, keep your pipeline.

Quick Start

Up and running in seconds

Grab the prebuilt binary, or compile from source. Both paths produce a single self-contained executable.

shell
# Download from Releases, then:
curl -L -o fastnlr.tar.gz \
  https://github.com/CropCoder/FastNLR/releases/download/v1.0.0/fastnlr-v1.0.0-linux-x86_64.tar.gz
tar -xzf fastnlr.tar.gz
cd fastnlr-linux-x86_64
./fastnlr --version

# Annotate a genome (prefix-derived subfiles)
./fastnlr -i genome.fasta -p result
shell
# Requires Rust 1.70+
git clone https://github.com/CropCoder/FastNLR.git
cd FastNLR
cargo build --release

# binary: target/release/fastnlr
./target/release/fastnlr -i genome.fasta -p result

The -p prefix auto-derives result.nlr.txt, result.nlr.gff, result.nlr.bed, result.motifs.bed, and result.nbarc.fasta.

Usage

Common workflows

One flag, one job. Compose exactly the outputs you need.

Basic annotation
fastnlr -i genome.fasta -o out.txt -g out.gff -b out.bed
Full run with reporting
fastnlr -i genome.fasta -p out --stats stats.tsv --summary --plot plots/ --checkpoint ckpt/
Extract loci sequences
fastnlr -i genome.fasta -p out -f genome.fasta loci.fasta 2000
Custom motif config
fastnlr -i genome.fasta -x custom_mot.txt -y custom_store.txt -p out

Correctness

Bugs fixed vs. the original

Validated against the original algorithm by cross-running the Java jar and diffing every output format.

1-a P-loop location logic (while(isPloop) → while(!isPloop)).
2-a stop-codon / unknown-aa replacement now actually applied (Java replaceAll return value was discarded).
3-f unified coordinate clamp on the last contig.
4-f multi-contig extraction — extracts from every chromosome, not just the first.
5-f extraction consistency — off-by-one in Java writeNLRLoci fixed, keeping -f consistent with reported coordinates.
6##date header set to the current system time (Java was non-deterministic).
7GFF ##source-version and source column relabeled FastNLR.
8p-value rendering in motif BED / export TSV now matches Java Double.toString.
