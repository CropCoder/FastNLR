FastNLR scans the six reading frames of a genome assembly for amino-acid motifs and assembles them into complete and partial NLR loci with multithreading, memory-mapped input, checkpoint resume, and coordinate-consistent output.

Install

Up and running in one command

Use the native desktop application on Windows or macOS, install the Linux CLI from bioconda, or build from source.

Windows desktopx64

Download the NSIS installer for Windows 10/11. WebView2 is required.

Download from Releases
macOS desktopARM64

Download from Releases
Linux CLIx86_64

Use the self-contained glibc 2.17+ binary or install through bioconda.

Choose CLI download
shell
# recommended: install from bioconda
conda install bioconda::fastnlr

# add channels explicitly if they are not in your conda config
# (conda-forge must come before bioconda)
conda install -c conda-forge -c bioconda bioconda::fastnlr

# then annotate a genome
fastnlr -i genome.fasta -o result

shell
# Requires Rust 1.85+
git clone https://github.com/CropCoder/FastNLR.git
cd FastNLR
cargo build --release

# binary: target/release/fastnlr
./target/release/fastnlr -i genome.fasta -o result

The -o directory contains the full result set prefixed by the genome filename: *.nlr.txt, *.nlr.gff, *.nlr.bed, *.motifs.bed, *.nbarc.fasta, *.loci.fasta, *.stats.tsv, *.summary.txt, and *.summary.json. Package page: anaconda.org/bioconda/fastnlr.

Usage

Common workflows

One flag, one job. Compose exactly the outputs you need.

Basic annotation
fastnlr -i genome.fasta -o results
Multithreading
fastnlr -i genome.fasta -o results -t 8
Flexible seeding (on by default)
fastnlr -i genome.fasta -o results --no-flexible-seed # opt out
Custom motif config
fastnlr -i genome.fasta -x custom_mot.txt -y custom_store.txt -o results
Extended RNL / TIR library
source data/motif_library_rnl_tir/flags.sh # adds 8 motifs
GFF3-guided protein mode
fastnlr -i genome.fasta --gff annotation.gff3 -o annotation_results

CLI reference

Browse options by task. Short flags are -i/-x/-y/-o/-t/-n; run fastnlr --help for the command-line reference.

-i <genome.fasta>Required

Genome FASTA input, optionally gzip-compressed.

--gff <annotation.gff3>Optional

Use GFF3 gene models instead of six-frame scanning. The longest CDS transcript is selected per gene.

-o <OUTPUT.DIR>Required

Output directory. It is created if missing, and the input filename becomes the output prefix.

-x <mot.txt>Built-in

Optional PWM profile. The standard profile is embedded when omitted.

-y <store.txt>Built-in

Optional CDF profile paired with the custom PWM file.

--flank <bp>2000

Flanking bases included on each side of an extracted locus sequence.

-t <n>Auto

Worker threads. Use no more than the number of physical CPU cores.

-n <n>1000

Number of fragments processed per batch.

--checkpoint <dir>Resume

Save and reload validated motif results. Input, profiles, thresholds and assembly settings are fingerprinted.

--progress <mode>auto

Select auto, bar, simple or off progress reporting.

--log-level <level>info

Set trace, debug, info, warn or error logging.

--flexible-seed <n>3

Seed when at least n distinct NB-ARC motifs appear in strictly increasing rank order. Enabled by default.

--no-flexible-seedStrict

Use exact motif-id seed combinations only.

--require-ploopPrecision

Require motif_1 for flexible seeding.

--relaxed-seed <n>Alternative

Accept a consecutive run containing at least n NB-ARC motifs. Requires --no-flexible-seed.

--motif-accept-p <p>1e-5

Final motif acceptance p-value threshold.

--motif-prelim-p <p>1e-4

Cheap prefilter threshold applied before full p-value evaluation.

--motif-category ID=CATMetadata

Declare categories outside the built-in rules, for example 21=CC,25=TIR. Repeatable or comma-separated.

--seed-combination IDSSeeds

Add an exact seed combination such as 21,4; separate multiple combinations with semicolons.

--signature IDSFilter

Add a local fragment signature such as 25,26; separate multiple signatures with semicolons.

--gff <FILE>Mode

Parse plain or gzipped GFF3, extract CDS and classify translated proteins with ordered HMM-only evidence. PWM and DNA-only flags are rejected.

--hmm <FILE>Repeatable

Add or override HMM models by accession; each file may contain multiple models.

Features

Built for speed, shipped self-contained

A self-contained pipeline that installs from bioconda and runs out of the box on any FASTA — no extra config files, no setup.

High performance

Rust with rayon multithreading, memory-mapped FASTA parsing, and SIMD (wide) cross-window scoring. Plant genomes finish in seconds to minutes.

Zero-config binary

The standard mot.txt (PWM) and store.txt (CDF) configs are embedded at compile time. Run on any FASTA with no extra files.

Coordinate-consistent

Loci FASTA headers match the sliced sequence after applying --flank and contig-boundary clamping. GFF/BED report the unflanked core locus, so the intervals are equal only when --flank 0.

GFF3-guided protein mode

Add --gff to select the longest CDS transcript per annotated gene, translate it from the genome, and classify the protein with 23 bundled Pfam HMMs. LRR is accepted as C-terminal evidence only when it lies after NB-ARC. --hmm adds your own models.

Resumable runs

--checkpoint saves motif results atomically after a complete scan; reruns skip the expensive scanning step and go straight to assembly. A versioned manifest rejects stale inputs, profiles, thresholds or runtime rules instead of silently reusing mismatched results.

Rich reporting

Human-readable summary and TSV statistics (global / per-chromosome / per-motif) out of the box — no external tools.

Flexible seeding, on by default

Category/rank-based seeding runs out of the box and recovers divergent NLR/RNL loci. It is additive — it never drops a locus that the exact motif-id seed combinations would have found (--no-flexible-seed restores the strict behaviour).

HMM-assisted N-terminal domains

When the PWM library does not identify a CC/TIR domain, the locus is checked with the bundled HMMER profiles also used in GFF3-guided protein mode. HMM hits fill the missing N-terminal domain instead of leaving a bare NBARC-LRR.

Tandem-repeat aware assembly

Repeated or duplicated domain units and trailing NB-ARC segments are merged back into their parent locus, so a single gene is not reported as several split loci.

Motif library

Extended RNL / TIR library

The default build ships 22 motif profiles: the classic 20 plus conservative RNL/helper-CC profiles 21 and 23. The repository also contains the full optional 28-motif RNL/TIR library.

MotifsWhat they add
21–24RNL / helper-NLR N-terminal CC motifs (ADR1, NRG1 and Solanaceous NRC); 21 and 23 are also present in the conservative default profile.
25–28TIR-family motifs, covering short and TIR-only loci that the standard [18,15,13] seed could miss.
shell
# enable the extended library (declares categories, seeds and signatures)
source data/motif_library_rnl_tir/flags.sh
fastnlr -i genome.fasta -o out \
  -x data/motif_library_rnl_tir/mot.txt \
  -y data/motif_library_rnl_tir/store.txt \
  --motif-category "$TIS_MOTIF_CATEGORY" \
  --seed-combination "$TIS_SEED_COMBINATION" \
  --signature "$TIS_SIGNATURE"

Because these motifs live outside the built-in rule tables they must be enabled together with their declared categories, seeds and signatures; flags.sh holds the complete parameter lists. Historical Wm82 testing showed improved RNL/helper-NLR coverage; current RefPlantNLR measurements are reported in the performance table below. See the library README for the design rationale and regeneration workflow.

Throughput holds at roughly 3.7 Mb/s end to end, and peak memory stays close to 1:1 with genome size (ratios 0.97–1.15 in the benchmark) — budget RAM of the same order as the assembly. Multithreading scales 13–19× from 4 to 128 threads on the largest genomes; keep -t at or below the physical core count, since oversubscription costs performance.

Correctness

Implementation notes

Unit, integration and documentation tests cover coordinate mapping, six-frame translation, motif scanning, three-step assembly with tandem-repeat absorption, protein-mode domain classification, seeding rules, checkpoint integrity, strict profile parsing, and every output format.

1The NB-ARC alignment FASTA uses corrected P-loop location logic.
2The NB-ARC alignment FASTA replaces stop codons and unknown amino acids with _.
3The loci FASTA applies a unified coordinate clamp on the last contig.
4The loci FASTA extracts from every contig, not only the first.
5The loci FASTA keeps extracted coordinates consistent with the reported GFF/BED coordinates.
6##date uses the current system time; checkpoint resumes retain the first-run timestamp for byte-identical output.
7GFF ##source-version and source column relabeled FastNLR.
8p-value rendering in motif BED / export TSV uses scientific notation for very small values.

Version history

Release timeline of FastNLR with a short summary of what changed in each version.

v1.9.2 2026-11-12

HMM filtering, completeness finalization, and deterministic motif output now share the same result path across fresh runs and checkpoint recovery. Release assets use the platform-specific Windows installer name and omit separate SHA256 summary files.

v1.9.1 2026-11-10

GFF3-guided gene protein annotation with longest-transcript selection, CDS translation, streaming multithreaded HMM/PWM scanning, protein/CDS/genomic domain coordinates, and an optional annotation workflow across CLI, desktop, and Web APIs.

v1.8.0 2026-11-09

Native Windows and Apple Silicon desktop applications with live progress, cancellation, persistent history, result tables, summary charts, and automated GitHub release packaging.

v1.7.2 2026-11-08

TIR-specific significance threshold, evidence-weighted N-terminal arbitration, and completeness reporting temporarily disabled.

v1.7.0 2026-11-03

Web server, service layer, desktop scaffold, and visualization; loci extraction restricted to the matching contig; release asset naming adjustments.
